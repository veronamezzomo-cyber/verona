# **App Name**: Layout Forge

## Core Features:

- AI Layout Variation Generator: Generate three distinct UI layout variations using a tool-based Genkit flow, outputting structured vector shapes from natural language prompts.
- Vector Editor Studio: A comprehensive canvas for visual manipulation including drag-and-drop positioning, resizing, and precise color editing of SVG groups.
- Named-Group SVG Builder: Constructs high-fidelity SVG code with semantic ID naming (e.g., logo, search-bar) specifically optimized for Adobe Illustrator and After Effects importing.
- Layered PDF Exporter: Custom PDF generation engine that utilizes Optional Content Groups (OCGs) to maintain true edit-ready layers across different software suites.
- UI Component Library: Access a suite of pre-defined, vector-based templates for chatbots, dashboards, and UI elements via a side-panel toolbar.
- Project Persistence: Cloud-based saving and synchronization of all project states and layout histories.

## Style Guidelines:

- A dark architectural theme. Background: Deep Navy (#0A0E27); Primary: Electric Blue (#3B82F6) for active tools; Accent: Vivid Violet (#8B5CF6) for generative components.
- Font pairing: 'Space Grotesk' for technical headings and buttons to evoke a computerized aesthetic, and 'Inter' for property panels and interface text to ensure machined precision.
- A workbench layout with a 1280x720 centered viewport, flanked by a minimalist property panel on the right and an asset library on the left.
- Geometric line-art icons that mirror the rounded-corner philosophy (min 8px radius) found within the generated UI elements.
- Smooth, mathematical transitions for object manipulation and immediate canvas feedback as visual parameters are updated.
